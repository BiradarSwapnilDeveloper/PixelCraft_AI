# Google Search Console Performance Data Directory

Place the CSV exports downloaded from Google Search Console into their respective folders below:

### 1. `data/gsc/current/` (Latest 28 Complete Days)
- `queries.csv`
- `pages.csv`
- `countries.csv`
- `devices.csv`

### 2. `data/gsc/previous/` (Preceding 28 Days Comparison)
- `queries.csv`
- `pages.csv`
- `countries.csv`
- `devices.csv`

### 3. `data/gsc/three_months/` (Latest 3 Complete Months)
- `queries.csv`
- `pages.csv`
- `countries.csv`
- `devices.csv`

### 4. `data/gsc/pages/` (Page-Filtered Query Exports)
- `image_compressor_queries.csv` (Filtered for `tools/image-compressor.html`)
- `format_converter_queries.csv` (Filtered for `tools/format-converter.html`)
- `qr_generator_queries.csv` (Filtered for `tools/qr-generator.html`)
- `smart_resize_queries.csv` (Filtered for `tools/smart-resize.html`)
