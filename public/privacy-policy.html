3. Granular Tool-by-Tool Data Processing & Memory Lifecycle

PixelCraft AI operates under a strict, dual-tier processing architecture. We distinguish with surgical precision between 100% Client-Side Local Execution and Ephemeral Server-Assisted Processing:

3.1 Client-Side Local Utilities (Zero Network Transmission • 0 Bytes Uploaded)

For the vast majority of our tool catalog, media files and plaintext payloads NEVER leave your device. They are processed entirely within your browser's local sandbox utilizing HTML5 Canvas APIs, WebAssembly (Wasm), the Web Audio API, Web Workers, and the W3C Web Crypto API:

  • Smart Image Compressor: Compresses JPEG, PNG, and WebP images directly via HTML5 2D Canvas contexts. Byte streams and raw pixel matrices exist solely in temporary JavaScript TypedArrays in volatile device RAM and are cleared upon garbage collection. Zero bytes are uploaded to any server.
  • Format Converter: Decodes and re-encodes graphic assets locally in your browser sandbox using Canvas toBlob() and WebAssembly decoders. No network traffic is initiated.
  • Image Resizer & Canvas Cropper: Performs bicubic and bilinear pixel interpolation entirely within client hardware RAM. Exported files are written directly to local browser download blobs.
  • Text & Visual Watermark Generator: Layers graphical watermarks, alpha transparencies, and typography onto carrier canvases client-side. No watermark assets or source images are transmitted externally.
  • EXIF Metadata Viewer & Header Stripper: Reads and visualizes binary EXIF, TIFF, GPS, and IPTC segments via local JavaScript ArrayBuffer parsers. Stripping metadata generates a clean, sanitized JPEG canvas entirely on your machine.
  • Digital Fingerprint Wiper: Erases hardware fingerprint markers, injects micro-level canvas noise to thwart browser fingerprinting trackers, and wipes EXIF headers 100% client-side without any network request.
  • Advanced Decoy Steganography: Performs client-side PBKDF2 key stretching (100,000 iterations), AES-256-CBC encryption, HMAC-SHA256 authentication tag computation, and 2D prime-stride pixel luminance dispersion strictly within browser memory. Your confidential messages, decoy texts, carrier photos, and passphrases are never transmitted over the internet.
  • Audio Steganography: Embeds encrypted payload bits into audio PCM waveforms using the HTML5 Web Audio API. Audio processing occurs entirely on your device's audio subsystem with zero server communication.
  • Standard QR Code Generator: Renders static and dynamic QR code matrices directly to an HTML5 Canvas element via localized JavaScript algorithms. Entered URLs, Wi-Fi credentials, and contact cards remain strictly on your client screen.

3.2 Ephemeral Server-Assisted Utilities (Encrypted HTTPS • Volatile Ephemeral Execution)

A limited set of advanced security, AI, and link-sharing features require server-side execution. For these specific tools, data is transmitted strictly over TLS 1.3 encrypted HTTPS connections under ironclad ephemeral retention constraints:

  • Forensic Image Sanitizer & Cryptographic Scanner: Uploaded images are transmitted to /api/tools/forensic-sanitize and /api/tools/verify-seal. Processing operates exclusively in volatile server RAM (multer.memoryStorage(), 50MB limit) to inspect EXIF/GPS metadata, scan for trailing binary malware/stego payloads, strip non-conforming headers via Libvips (sharp), and embed an HMAC-SHA256 dual-anchor cryptographic seal. Uploaded files are never written to persistent disk and are discarded immediately upon HTTP response completion.
  • PDF-to-Link Ephemeral File Sharing: Uploaded PDF files are stored on isolated, unindexed server storage for a strict, maximum lifecycle of 24 hours to serve user-requested public download links (/p/:id). Documents are never stored in our MongoDB database, are never indexed by web search engines, and are never utilized for AI model training. An automated hourly cron job permanently unlinks, shreds, and purges all expired files. For full technical retention specifics, consult our data-practices.html inventory.
  • AI Audio & Video Dubbing: Audio and video chunks are written to temporary system storage (os.tmpdir()) and deleted (unlinkSync) immediately after processing. Transcripts and synthesized speech are passed to trusted AI APIs (Groq for speech-to-text, Google Cloud for TTS) under transient inference rules. Media is never retained for training.
  • Phishing & Threat Link Scanner: URLs submitted to /api/scan-link undergo automated server-side DNS resolution, TLS certificate validation, heuristic entropy analysis, and homoglyph evaluation. Destination server headers and redirect hops are evaluated in real-time. Target URLs are analyzed transiently and are not tied to user identity records.
  • AI 3D QR Code Generator (Optional Cloud Mode): When users voluntarily opt into neural 3D QR code styling, the prompt and matrix structure are routed to cloud inference GPUs (Hugging Face / Stable Diffusion XL). Standard QR codes remain 100% local in your browser.

7. Zero-Knowledge Cryptographic Architecture & Plausible Deniability

PixelCraft AI adheres to mathematical, open-source cryptographic principles to safeguard your digital sovereignty:

  • W3C Web Crypto API Standard: All browser-side symmetric encryption utilizes the hardware-accelerated, native W3C Web Crypto API. We do not use proprietary, unaudited JavaScript math routines.
  • Authenticated Encryption (Encrypt-then-MAC): In Advanced Decoy Steganography, payloads are protected via AES-256-CBC coupled with HMAC-SHA256 authenticated tags. The ciphertext and initialization vector are cryptographically verified prior to decryption, rendering bit-flipping attacks impossible.
  • Multi-Channel Plausible Deniability: Users may generate separate Real and Decoy channels embedded within identical pixel matrices. Coerced entry of a decoy passphrase decrypts solely benign decoy text, while the authentic payload remains mathematically indistinguishable from pseudorandom carrier noise.
  • Dual-Anchor HMAC Integrity Seals: Sanitized forensic images receive an HMAC-SHA256 seal calculated across both normalized metadata tags and the visual pixel luminance domain. Re-submitting an image to /api/tools/verify-seal validates that pixel matrices have not undergone post-export tampering.
  • Zero Master Keys: We maintain zero encryption key escrow. Passphrases exist solely in your mind or offline password managers. We cannot decrypt your files under any circumstance.
